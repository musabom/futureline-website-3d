Build a production-ready full-stack web application called “FutureLine”.

FutureLine is a professional AI, training, and digital services company.
The platform must support:

1) Public-facing website (courses + services + AI)
2) Secure Admin Portal (full CRUD management)
3) Online course learning area (LMS-lite)
4) In-person classroom course management
5) AI-powered course recommendation tool

---------------------------------------------------
TECH STACK REQUIREMENTS
---------------------------------------------------

Use:
- Next.js (App Router)
- TypeScript
- TailwindCSS (custom theme based on brand colors)
- PostgreSQL
- Prisma ORM
- NextAuth (role-based authentication)
- Stripe for payments
- Modular architecture (scalable structure)
- Clean folder separation (app, components, lib, admin, api, dashboard)

Prepare app for easy future deployment.
